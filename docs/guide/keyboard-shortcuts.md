# Keyboard shortcuts

Everything in Tessera works from the keyboard. <kbd>Mod</kbd> means <kbd>⌘</kbd> on macOS and
<kbd>Ctrl</kbd> on Windows and Linux.

::: tip The list in the app is always current
Press <kbd>?</kbd> (or <kbd>Mod</kbd>+<kbd>/</kbd>) anywhere outside a text field to see every
shortcut, including the ones plugins add. **Settings → Keyboard shortcuts** shows the same list.
:::

## Everywhere

| Action                          | Shortcut                                                               |
| ------------------------------- | ---------------------------------------------------------------------- |
| Command palette and search      | <kbd>Mod</kbd>+<kbd>K</kbd>                                            |
| New page                        | <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> (desktop app: also <kbd>Mod</kbd>+<kbd>N</kbd>) |
| Show or hide the sidebar        | <kbd>Mod</kbd>+<kbd>\\</kbd>                                           |
| Switch light and dark theme     | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>                           |
| Settings                        | <kbd>Mod</kbd>+<kbd>,</kbd>                                            |
| Keyboard shortcuts              | <kbd>?</kbd> or <kbd>Mod</kbd>+<kbd>/</kbd>                            |
| Close a menu, dialog or panel   | <kbd>Esc</kbd>                                                         |

## Page tree (sidebar)

Click a page in the sidebar, or tab into the tree, then:

| Action                              | Shortcut                                               |
| ----------------------------------- | ------------------------------------------------------ |
| Move between pages                  | <kbd>↑</kbd> <kbd>↓</kbd>                              |
| Expand or collapse                  | <kbd>→</kbd> <kbd>←</kbd>                              |
| Open the page                       | <kbd>Enter</kbd>                                       |
| Move the page up or down            | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> |
| Nest it under the page above        | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>→</kbd>           |
| Move it out one level               | <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>←</kbd>           |

To close every expanded page at once, hover over or tab to the **Pages** heading and choose
**Collapse all**.

## Page title

| Action                         | Shortcut                                        |
| ------------------------------ | ----------------------------------------------- |
| Go to the first block          | <kbd>Enter</kbd> or <kbd>↓</kbd> at the end of the title |
| Back to the title              | <kbd>↑</kbd> at the start of the first block    |

## Editor

| Action                          | Shortcut                                                         |
| ------------------------------- | ---------------------------------------------------------------- |
| Slash menu                      | <kbd>/</kbd>                                                     |
| Link a page                     | <kbd>[</kbd><kbd>[</kbd> or <kbd>@</kbd>                         |
| Tag                             | <kbd>#</kbd> followed by a name                                  |
| Bold                            | <kbd>Mod</kbd>+<kbd>B</kbd>                                      |
| Italic                          | <kbd>Mod</kbd>+<kbd>I</kbd>                                      |
| Underline                       | <kbd>Mod</kbd>+<kbd>U</kbd>                                      |
| Undo                            | <kbd>Mod</kbd>+<kbd>Z</kbd>                                      |
| Redo                            | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>                     |
| Indent or outdent a list item   | <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd>                 |
| Select the current block        | <kbd>Esc</kbd>                                                   |
| Move the block selection        | <kbd>↑</kbd> <kbd>↓</kbd> while blocks are selected              |
| Extend the block selection      | <kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd> while blocks are selected |
| Move blocks                     | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd>      |
| Duplicate blocks                | <kbd>Mod</kbd>+<kbd>D</kbd>                                      |
| Delete selected blocks          | <kbd>Delete</kbd> or <kbd>Backspace</kbd>                        |

Markdown shortcuts (`# `, `- `, `1. `, `[] `, `> `, ```` ``` ````, `---`, `**bold**`, `*italic*`,
`` `code` ``, `~~strike~~`, `==highlight==`) are listed in [The editor](./editor#blocks).

## Databases (table view)

| Action                         | Shortcut                                                  |
| ------------------------------ | --------------------------------------------------------- |
| Move between cells             | <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd>, <kbd>Tab</kbd>, <kbd>Shift</kbd>+<kbd>Tab</kbd> |
| Edit the cell                  | <kbd>Enter</kbd>                                          |
| Stop editing                   | <kbd>Esc</kbd>                                            |
| Add a row                      | <kbd>Mod</kbd>+<kbd>Enter</kbd>                           |
| Copy and paste cells           | <kbd>Mod</kbd>+<kbd>C</kbd>, <kbd>Mod</kbd>+<kbd>V</kbd>  |

## Command palette

| Action                     | Shortcut                        |
| -------------------------- | ------------------------------- |
| Move through results       | <kbd>↑</kbd> <kbd>↓</kbd>       |
| Open or run                | <kbd>Enter</kbd>                |
| Close                      | <kbd>Esc</kbd>                  |

## Desktop app

| Action                                   | Shortcut                                               |
| ---------------------------------------- | ------------------------------------------------------ |
| Quick capture, from any app              | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd>       |
| New page                                 | <kbd>Mod</kbd>+<kbd>N</kbd>                            |

The desktop menus (File, Edit, View, Window, Help) use your platform's standard shortcuts.
